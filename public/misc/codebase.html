System Components

1. AgentRunner ▼
A "justfile-style" command launcher serving as the central hub. Manages command registration, hooks (pre_hook/post_hook), and context management.
2. SetupOrchestrator ▼
Uses Gemini 3 Pro to analyze codebase structure and generate a SetupPlan. Parallel executes tasks via Gemini 3 Flash and synthesizes a unified SetupReport.
3. InteractiveSetupAgent ▼
Facilitates human-in-the-loop workflows. Guides users through Q&A for database modes, installation types, and environment variables.
4. SetupToolsManager ▼
Provides function calling capabilities. Tools include: Dependency Checking, Script Execution, Environment management, and Logging.
