/specs

Spec-Driven Development (SDD)

We must move away from unstructured development. Instead, we adopt Spec-Driven Development. A specification file acts as the "Algorithm of Thought"—defining *what* is being built and *why*.

user_auth_update.md ● Approved 
# Spec: User Authentication Update

## Problem Statement
Migrate from local JWT to Auth0 providers.

## Technical Implementation
- Modify `auth_middleware.ts`
- Update `User` schema in Prisma

## Validation
- Run `npm test`, ensure 15 auth tests pass.

Context Priming & Session Initialization

Metainstructions

Unlike /specs which are feature-specific, these are reusable scripts for the agent's operational behavior. Create a command like prime.md.

  • Read README.md for high-level goals.
  • Run ls -R to visualize file structure.
  • Summarize core architecture.
# Command: Prime
Role: You are a Senior Architect.
Action: Read /ai_docs/architecture.md...
Output: Provide a 3-sentence summary of our tech stack and current sprint goals.
